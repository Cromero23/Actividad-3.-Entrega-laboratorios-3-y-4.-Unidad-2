
# Unidad II — Entrega de Laboratorios 1 y 2

## Descripción

Este repositorio contiene las actividades de la Unidad II relacionadas con la seguridad y protección de bases de datos mediante PostgreSQL.

Se incluyen los laboratorios 1 y 2, sus scripts SQL, documentación, resultados y evidencias de las prácticas realizadas.

## Laboratorio 01 — Protección y privacidad de datos

Actividades de seguridad relacionadas con el control de acceso, usuarios, roles, permisos y protección de la información.

[Consultar Laboratorio 01](laboratorio-01-proteccion-datos/)

## Laboratorio 02 — Cifrado, credenciales y comunicaciones seguras

Implementación y verificación de mecanismos de seguridad mediante:

- Hash de contraseñas con bcrypt.
- Cifrado simétrico mediante pgcrypto.
- Gestión de claves criptográficas.
- Configuración de TLS en PostgreSQL 16.
- Verificación de conexiones mediante pgAdmin 4 y psql.
- Análisis de riesgos y políticas de protección.

Las capturas de pantalla se encuentran incorporadas en los archivos Markdown.

[Consultar Laboratorio 02](laboratorio-02-cifrado-credenciales/README.md)

## Herramientas utilizadas

- PostgreSQL 16
- pgAdmin 4
- PowerShell
- OpenSSL
- Git y GitHub
- Visual Studio Code

## Consideraciones de seguridad

Los datos y contraseñas utilizados en las demostraciones son ficticios.

No deben incluirse contraseñas reales, claves privadas, tokens de acceso ni otros secretos en el repositorio.
